# 👸 Oisha-OS: The Surgical Agentic COO

Oisha-OS is an advanced, autonomous internal management system designed for **Jon Branding Agency**. It serves as a "Surgical COO," shifting the focus from client micromanagement to strict internal team workflow, operational discipline, and high-precision execution.

## 🛡️ Core Capabilities

*   **Autonomous Lead Management**: AI-driven "Surgical Missions" that map AmoCRM pipelines to specific roles (Hunter, Setter, Farmer).
*   **Negotiation Engine**: Context-aware, role-specific sales instructions generated based on deep chat analysis.
*   **Enterprise Reporter**: Daily actionable plans and team efficiency audits that enforce accountability.
*   **24/7 Cloud Autonomy**: Fully containerized and deployed on Google Cloud Run, utilizing Turso for hybrid cloud/local database resilience.
*   **Wow-Factor Client Experience**: Ensuring every client interaction feels premium, state-of-the-art, and meticulously managed.

## 🚀 Technology Stack

- **Core**: Python / Telethon (High-performance Userbot)
- **AI Brain**: Google Gemini 1.5 Pro / GPT-4o
- **Database**: Turso (LibSQL) with Singleton DatabasePool & SmartRow adapter
- **Infrastructure**: Google Cloud Run, Cloud Secret Manager, Cloud Build
- **CRM**: AmoCRM API Integration
- **Sync**: Airtable Sync Engine

## 👸 The Persona: Oisha

Oisha is not just a bot; she is an **Internal Surgical COO**. Her tone is professional, authoritative, and focused on operational excellence. She doesn't just notify; she directs, audits, and ensures that no lead is left behind.
