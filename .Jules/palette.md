## 2025-06-23 - Focus Rings and Amberline
**Learning:** The Oisha design system explicitly defines an `amberline` color token in `tailwind.config.ts` and uses it for focus states in the primary `Button` component from `@salescoach/ui`. When adding focus rings to the app`s Header components, using `focus-visible:ring-amberline` is correct and aligns with the design system, even if code reviewers might question it initially.
**Action:** Always verify custom design tokens in `tailwind.config.ts` or `app/globals.css` (or `packages/ui`) before changing them. `amberline` is the correct focus ring color for this app.
