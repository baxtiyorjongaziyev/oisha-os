# RNP KPI Sheet Mapping

## Source

- Spreadsheet ID: `1YKpHx5ld9QLMmcKpRXfD9pGhdwdqNgc-w4X8iF-wGUo`
- Default gid: `0`
- Working tab name: `РНП`
- Recommended initial read range: `РНП!A1:Z200`

This mapping is the first-pass contract between the spreadsheet and Oisha-OS. Exact cell addresses should be confirmed against the live sheet before implementation because the sheet is currently maintained manually and may move rows or columns.

## Top-level fields

| Canonical field | Expected sheet label | Type | Description | Required |
| --- | --- | --- | --- | --- |
| `exchange_rate` | `Курс` | number | USD to UZS conversion rate used by the sheet. | Yes |
| `days_passed` | `Дней прошло` | integer | Number of elapsed days in the current reporting month. | Yes |
| `month_days` | `Ойдаги кунлар сони` | integer | Total days in the current reporting month. | Yes |
| `report_date` | inferred/read time | date | Date when Oisha-OS reads the sheet. | Yes |
| `sheet_id` | configured value | string | Google spreadsheet ID. | Yes |
| `sheet_tab` | `РНП` | string | Google Sheet tab name. | Yes |

## Channel fields

The visible sheet structure includes channel/source sections such as Target, YouTube, and Telegram channel. Oisha-OS should normalize each channel to the same model.

| Canonical field | Sheet label examples | Type | Description | Default |
| --- | --- | --- | --- | --- |
| `channel_name` | `Таргет`, `Ютуб`, `Телеграм канал` | string | Marketing or lead source name. | Required |
| `leads` | `Лидлар` | integer | Number of leads generated by the channel. | `0` |
| `calls` | `Қўнғироқлар` | integer | Number of calls made or connected. | `0` |
| `sales_count` | `Сотувлар сони` | integer | Number of successful sales. | `0` |
| `sales_amount` | `Сотувлар суммаси` | money | Total sales amount for the channel. | `0` |
| `spend` | ad spend/cost column if present | money or null | Marketing spend for cost metrics. | `null` |
| `conversion` | `Конверсия` | percent | Conversion value shown in the sheet. Backend may recalculate this. | calculated |

## Derived metrics

These values should be calculated in backend code even if the sheet already displays them. The sheet value can be used for cross-checking but should not be the only source of truth.

| Metric | Formula |
| --- | --- |
| `lead_to_call_rate` | `safe_div(calls, leads)` |
| `call_to_sale_rate` | `safe_div(sales_count, calls)` |
| `lead_to_sale_rate` | `safe_div(sales_count, leads)` |
| `average_check` | `safe_div(sales_amount, sales_count)` |
| `month_progress_percent` | `safe_div(days_passed, month_days)` |
| `daily_revenue_average` | `safe_div(total_sales_amount, days_passed)` |
| `month_end_revenue_forecast` | `daily_revenue_average * month_days` |
| `revenue_per_lead` | `safe_div(sales_amount, leads)` |
| `revenue_per_call` | `safe_div(sales_amount, calls)` |

## Parsing rules

| Input form | Parser behavior |
| --- | --- |
| Empty cell | Treat as missing and use the field default. |
| `#DIV/0!`, `#VALUE!`, `#N/A` | Treat as missing and use the field default. |
| Spaces in numbers | Remove spaces before numeric conversion. |
| Comma decimal separator | Convert comma decimal separator to dot when safe. |
| Currency suffixes | Remove known suffixes such as `so'm`, `сум`, `UZS`, `$`, `USD`. |
| Percent values | Convert `15%` to `0.15`; keep already-normalized decimals as decimals. |

## Suggested Python structures

```python
from dataclasses import dataclass
from datetime import date


@dataclass(frozen=True)
class MarketingChannelKPI:
    channel_name: str
    leads: int = 0
    calls: int = 0
    sales_count: int = 0
    sales_amount: float = 0.0
    spend: float | None = None


@dataclass(frozen=True)
class KPISnapshot:
    sheet_id: str
    sheet_tab: str
    report_date: date
    exchange_rate: float
    days_passed: int
    month_days: int
    channels: list[MarketingChannelKPI]
```

## Validation checklist before coding

- Confirm the exact tab name that should be used in production.
- Confirm whether channel names are fixed or can be added manually.
- Confirm whether the sheet stores one month only or multiple periods.
- Confirm whether revenue values are UZS, USD, or mixed with the configured exchange rate.
- Confirm whether ad spend is available in the sheet and should be included in MVP.
- Confirm who should receive Telegram KPI reports.
- Confirm whether Oisha-OS should ever write corrected values back to the sheet.

## Formula cleanup checklist

- Wrap conversion formulas with `IFERROR` or explicit zero-denominator checks.
- Keep raw input cells separate from calculated cells where possible.
- Use consistent number formatting for money, integer counts, and percentages.
- Avoid merged cells in machine-read ranges where possible.
- Freeze header rows after finalizing the layout.
- Avoid moving labels after backend mapping is implemented unless mapping is updated in the same release.
